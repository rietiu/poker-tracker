# MTT 模式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Session 加 MTT（錦標賽）種類：買入＋重買、盲注級別隨時升（BB ante），手牌用籌碼計，歷史只顯示總投入。

**Architecture:** 新純函數模組 `src/mtt.js` 集中所有 MTT 判斷（`isMtt`、`handBlinds`、`chipSym` 等）；底池／淨額 helper 加 `ante` 參數；各畫面用 helper 取代直接 `parseSB(session.game)` 同 `currencySymbol(session.currency)`。現金局行為不變。

**Tech Stack:** React 19 + Vite、IndexedDB（idb）、vitest（`npm test`，測試喺 `test/*.test.js`）。

**Spec:** `docs/superpowers/specs/2026-11-16-mtt-design.md`

## Global Constraints

- 現金局（冇 `kind` 或 `kind: 'cash'`）所有行為、文字、數字完全不變；現有 199 個 test 全部繼續過。
- MTT：只支援 BB ante；籌碼唔加貨幣符號；冇 rake／jackpot；唔計盈虧，只顯示總投入（真錢，`session.currency`）。
- 每手 MTT 牌開局時抄低 `hand.blinds = { level, sb, bb, ante }`；顯示／計算一律用手牌自己嘅 blinds，冇就用 session 目前級別。
- 介面文字：中英夾雜，跟現有畫面（例如「升盲」「Re-entry」「總投入」「Lv3」）。
- BB 數顯示到小數後一位（`46.3 BB`）。
- 舊資料唔使 migration；備份／還原唔使改。

```js
// MTT (tournament) sessions: everything kind-specific lives here.
// Cash sessions have no `kind` (or kind 'cash') and must behave exactly as before.
import { parseSB, parseBB, currencySymbol } from './utils.js';

export const ENTRY_TYPES = [
  { type: 'reentry', label: 'Re-entry' },
  { type: 'rebuy', label: 'Rebuy' },
  { type: 'addon', label: 'Add-on' },
];
const ENTRY_WORD = { buyin: 'buy-in', reentry: 're-entry', rebuy: 'rebuy', addon: 'add-on' };

export function isMtt(session) {
  return session?.kind === 'mtt';
}

export function currentLevel(session) {
  const levels = isMtt(session) ? session.levels || [] : [];
  const last = levels[levels.length - 1];
  if (!last) return null;
  return { level: last.level, sb: Number(last.sb) || 0, bb: Number(last.bb) || 0, ante: Number(last.ante) || 0 };
}

export function totalInvested(session) {
  return (session?.entries || []).reduce((s, e) => s + (Number(e.amount) || 0), 0);
}

export function entrySummary(session) {
  const counts = {};
  for (const e of session?.entries || []) counts[e.type] = (counts[e.type] || 0) + 1;
  return ['buyin', 'reentry', 'rebuy', 'addon']
    .filter(t => counts[t])
    .map(t => `${counts[t]} ${ENTRY_WORD[t]}${counts[t] > 1 ? 's' : ''}`)
    .join(' + ');
}

export function bbCount(chips, bb) {
  const b = Number(bb);
  if (!(b > 0)) return null;
  return Math.round((Number(chips) || 0) / b * 10) / 10;
}

export function nextLevelDraft(session) {
  const cur = currentLevel(session) || { sb: 0, bb: 0, ante: 0 };
  return { sb: cur.sb, bb: cur.bb, ante: cur.ante };
}

export function handBlinds(session, hand) {
  if (isMtt(session)) {
    const b = hand?.blinds || currentLevel(session) || { sb: 0, bb: 0, ante: 0 };
    return { sb: Number(b.sb) || 0, bb: Number(b.bb) || 0, ante: Number(b.ante) || 0 };
  }
  return { sb: parseSB(session?.game), bb: parseBB(session?.game), ante: 0 };
}

export function chipSym(session) {
  return isMtt(session) ? '' : currencySymbol(session?.currency);
}

export function levelLabel(b) {
  if (!b) return '';
  const base = `Lv${b.level} ${Number(b.sb).toLocaleString()}/${Number(b.bb).toLocaleString()}`;
  return Number(b.ante) > 0 ? `${base} (${Number(b.ante).toLocaleString()})` : base;
}
```

`src/pots.js`：

```js
// Chips each position put in over the whole hand (posted blinds included; a BB ante is dead money on BB).
export function handContributions(hand, sb = 1, bb = 2, ante = 0) {
  const total = {};
  for (const st of STREETS) {
    const actions = hand?.[st]?.actions || [];
    const isPre = st === 'preflop';
    const order = [...new Set([...(isPre ? ['SB', 'BB'] : []), ...actions.map(a => a.pos)])];
    if (order.length === 0) continue;
    const { committed } = computeStreetState(actions, order, order, 0, isPre ? { SB: sb, BB: bb } : {});
    for (const pos of order) total[pos] = (total[pos] || 0) + (committed[pos] || 0);
  }
  if (ante > 0) total.BB = (total.BB || 0) + ante;
  return total;
}
```

`src/utils.js`：

```js
export function heroBlindPosted(hand, sb = 1, bb = 2, ante = 0) {
  if (hand?.myPosition === 'SB') return sb;
  if (hand?.myPosition === 'BB') return bb + (Number(ante) || 0);
  return 0;
}
```

`heroInvested(hand, sb = 1, bb = 2, ante = 0)`：ante 係死錢，**唔可以**當作 hero 已經投入去 call 嘅金額。所以迴圈入面交畀 street state 嘅 preflop seed 仍然用 `heroBlindPosted(hand, sb, bb)`（冇 ante），迴圈完之後先加 `if (hand.myPosition === 'BB') total += Number(ante) || 0;`。用 test 驗證 `heroInvested(..., 200) === 400`。

`handNet(hand, opts = {})`：加 `const ante = opts.ante ?? 0;`；所有 `heroInvested(hand, sb, bb)` → `heroInvested(hand, sb, bb, ante)`；quick hand 嘅 `heroBlindPosted(hand, sb, bb)` → `heroBlindPosted(hand, sb, bb, ante)`。`sumNet` 已經將 `opts` 原樣傳落 `handNet`，唔使改。
